## Дополнение: обязанности роли без отдельного подразделения

Паспорт разбора выявил ранее не сопоставлявшийся блок 5.3 редакции 8: «Директор направления внутреннего аудита». Роль теперь участвует в сравнении под собственным названием с префиксом «Роль:», без добавления вымышленного подразделения. Из 20 пунктов 17 получили предварительное текстовое соответствие; три требуют отдельной проверки:

Родительский пункт содержит самостоятельное действие, поэтому не исключён как пустой заголовок. Нужна проверка полномочия. |
| 5.3.4: организация и проведение проверок для выполнения плана работ БВА | 5.3.5: проведение проверок и обеспечение выполнения плана; дочерние действия сопоставлены | Вероятна переформулировка. Порог словесного сходства не пройден, подтверждённой утратой не считается. |

Итого в расширенном анализе — **семь кандидатов**. Проверка NEG-1 теперь сверяет точные адреса всех семи вручную разобранных пунктов вместо прежнего общего ограничения на количество; лишний или пропущенный кандидат провалит проверку. Обязанности роли и отсутствие вымышленного подразделения дополнительно проверяет `coverage.test.js`. Предварительные соответствия роли также требуют проверки объектов работы и владельцев: сходный текст может повторяться у разных подразделений.
