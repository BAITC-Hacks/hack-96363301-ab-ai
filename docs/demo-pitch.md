# Демонстрация OrgDiff — 90 секунд

## Основная мысль

«Одно “не” в положении может изменить полномочие, хотя сходство значимых слов остаётся 100%. OrgDiff связывает изменения с ответственными, показывает точные основания и помогает подготовить решение для согласования».

## Маршрут

1. **0–15 секунд.** Нажать «Найти скрытые изменения». Сразу назвать пример синтетическим: исходные XLSX открыты для скачивания, это обычный анализ документов, а не записанный результат.
2. **15–35 секунд.** В «Контрпроверке» показать 100% сходства текста и пару «вправе согласовывать» → «не вправе согласовывать». Прочитать выделенные фрагменты. Объяснить: высокий процент не доказывает сохранение полномочий; изменение может быть намеренным.
3. **35–50 секунд.** Нажать «Сроки и периодичность»: ежемесячная проверка стала ежеквартальной. Затем «Обязанность и право»: «обязано» сменилось на «может». Показать вопрос эксперту и возможность раскрыть точные источники.
4. **50–70 секунд.** Вернуть «Все сигналы», нажать «Рассмотреть в плане» у запрета. Оставить «Передать на согласование», написать: «Уточнить намеренность запрета согласования договоров и нового владельца полномочия». Сохранить. Счётчик рассмотренных увеличился, а число открытых вопросов осталось прежним: согласование ещё впереди.
5. **70–90 секунд.** Выгрузить Excel. На листе «Контрпроверка» показать фрагменты обеих редакций, перейти по ссылке к источнику; на листе «План решений» — обоснование. Закончить: «Изменённое слово превращается в проверяемый вопрос с источниками и решением пользователя».

## Если есть ещё минута

Запустить комплект организатора и открыть «Карту ответственности». Показать перенос пункта 5.4.4б → 5.3.3б, открыть кандидата на утрату с похожими фрагментами. Затем в обычном учебном примере показать назначение ответственного за архив и проект формулировки. Обзор проверки потенциальных утрат: `docs/loss-review.md`.

## Что отвечать на вопросы

- **Где ИИ?** Сопоставление и выводы доступны локально. При наличии ключа модель дополнительно проверяет сопоставления по цитатам. Трассировка показывает реально полученные ответы; локальный результат не выдаётся за живой вызов модели.
- **Можно ли доверять ссылкам?** Пункты и цитаты берутся из парсера. Решения плана принимаются только для находок в отчёте, хранящемся на сервере; произвольный присланный отчёт не используется. Это проверка принадлежности источника, а не автоматическое доказательство правильности решения пользователя.
- **Что сохраняется?** Решения сохраняются в браузере по отпечатку комплекта. На сервере временно хранятся до 20 отчётов в течение двух часов. После перезапуска нужен повторный анализ; для того же комплекта можно восстановить решения из браузера.
- **Это система согласования?** Нет: это прототип подготовки плана. Нет пользователей, подписей и истории согласований. Для передачи результата предусмотрен Excel с пометкой «ПРОЕКТ».
- **Как проверяли?** Контрольный комплект организатора, независимые XLSX, негативные проверки источников и владельцев, проверка содержимого Excel и сквозной браузерный сценарий.
- **Ловит любое изменение смысла?** Нет. Контрпроверка использует явные признаки: отрицание, модальность, сроки и охват. Неизвестные конструкции, неоднозначные действия и пункты без сопоставления остаются предметом ручной проверки. Процент — сходство слов, не вероятность правильности вывода.
