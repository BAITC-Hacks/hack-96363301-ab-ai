Проверка до старта соревновательной части (делать во время check-in 09:00–12:00). Отвечай по-русски. Никакой разработки по кейсу — только готовность окружения.

Проверь фактическими командами и отчитайся по каждому пункту `OK` / `ПРОБЛЕМА + что делать`:

1. **Репозиторий.** `git remote -v` — origin должен быть `github.com/BAITC-Hacks/hack-96363301-ab-ai`. Ветка `main`, upstream настроен, рабочее дерево понятное.
2. **Доступ на запись.** Убедись, что push проходит: `git push` при отсутствии локальных изменений либо `git ls-remote origin`. Не создавай пустых коммитов для проверки.
3. **Личность коммитов.** `git config user.name` и `user.email` заполнены и совпадают с аккаунтом GitHub, под которым участник зарегистрирован.
4. **Секреты.** `.gitignore` закрывает `.env` и `.env.*`. Проверь, что ни один `.env` не отслеживается: `git ls-files | grep -i env`.
5. **Приватность репозитория.** Кибербез-регламент требует доступ только у команды и организаторов: `gh repo view --json visibility` должен дать `PRIVATE`.
6. **Инструменты.** Версии: `node`, `npm`, `python`, `pip`, `git`, `codex`. Если есть `docker` — тоже. Скажи, чего не хватает.
7. **Доступы от организаторов.** Проверь, активированы ли ChatGPT Pro, кредиты OpenAI API, NVIDIA Brev и ключ NVIDIA Build (ссылки и промокоды — в Telegram-боте или на платформе). В окружении должны быть `OPENAI_API_KEY` и `NVIDIA_API_KEY`. При оформлении ChatGPT Pro подтверждать подписку только если на странице указано `Due today: $0`.
8. **Сеть на площадке.** Подключение может быть **проводным Ethernet по DHCP**, а личные точки доступа, USB-модемы и раздача с телефона правилами запрещены — запасного канала не будет. Проверь: есть ли физический разъём RJ-45 (`Get-NetAdapter`), а если нет — готов ли и проверен ли переходник USB-C → RJ-45 с драйвером; стоит ли получение IP и DNS на автоматическое. Затем доступность критичного: `npm ping`, `pip download` пробником, GitHub, API моделей. Любая блокировка — скажи сразу, до старта.
9. **Состояние ноутбука.** Незакрытые обновления ОС (ставить заранее и перезагружаться, не в день хакатона), свободное место на диске, включённые антивирус и межсетевой экран, блокировка экрана. Заряд и зарядные устройства — напомни взять.
10. **Кеш зависимостей.** Предложи, что стоит скачать заранее на случай медленной сети: базовые шаблоны проектов, модели, крупные пакеты.
11. **Помощники.** Проверь, что агенты `hack-planner`, `hack-builder`, `hack-scout`, `hack-reviewer`, `hack-pitch` и команды `/hack-*` доступны из `~/.claude/`, а роли Codex — из `.codex/agents/`.
